Decisions:
- binding: an R3 base is proven against the loose /BIN copy. The DAT type-7 segment decodes in RAM to bytes identical to it: E00, E20, E90, WEP01 and WEP07 were seen fully equal. No decoder is needed for load-base proofs.
- binding: an overlay proof is a full file compare at 3 moments when the file stays intact. Otherwise it is a full compare at the load moment (entry breakpoint), then [base,text_end) only. text_end = TextExtent MAX_FUNC_END on the raw import, fixed in the script and never widened. OPTION text_end is 0x801c4858.
- binding: overlay windows are time-shared (0x800d5800 and 0x8017e500 change with the demo stage), so the proof moments must lie inside one residency window.
