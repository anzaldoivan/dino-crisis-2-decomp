## Deviations / expert notes
- Image base ≠ t_addr: psx_ldr sets image base = RAM base (`initPc & 0xFF000000` = 80000000, PsxLoader.java:228-254); forcing `-ramStart` to t_addr would trigger a YES/NO dialog and mis-map RAM. Gate instead: initialized block at t_addr starts at t_addr (`BASE_CHECK`). Both values printed.
- Ghidra install modified (mac_arm_64 natives added) — needed for psx_ldr analyzer; documented in the pin row. generalizable: Ghidra release zips lack macOS arm64 decompiler natives; psx_ldr's PsyQ Signatures analyzer silently stops after the first range without them.
- ScorePsyqVersions run as a direct analyzeHeadless command (no import.sh mode added).
