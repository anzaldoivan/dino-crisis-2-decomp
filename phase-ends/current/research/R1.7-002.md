### (3) Priority formula (regalloc.md:68-69, K2)
`pri = (int)(((double)(floor_log2(n_refs) * n_refs) / live_length) * 10000 * size)` (global.c:594 allocno_compare, per-allocno; local-alloc.c:1727 [2.8.1 pm] QTY_CMP_PRI, per-qty). Higher first; int-truncated; ties -> creation/regno order (global.c:609). n_refs loop-depth weighted (flow.c reg_n_refs += loop_depth); live_length from flow/sched1 (sched.c:5067 [2.8.1 pm]); equiv-reg (REG_EQUIV) live length doubled (local-alloc.c:1153 [2.8.1 pm]). Local-alloc: only single-block, single-death pseudos; <=3 qtys sorted by creation order (RC-11 bug); suggested qtys (phys-reg copies) allocated first. Global: pass 0 reuses regs_used_so_far, pass 1 opens fresh; no REG_ALLOC_ORDER on MIPS -> regno order $v0..$fp.
Caveat flagged by kit: K4 text claiming no caller-saves is FALSE; flag_caller_saves ON at -O2 (toplev.c:3387); caller-save slots are 4-byte packed, reload slots 8-rounded. Kit text with [2.8.1 pm] cites is from papermario's 2.8.1, so 2.95.2 drift is likely.
