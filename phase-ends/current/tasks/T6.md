Decisions:
- binding: one reason per candidate, the first match in the order not-a-census-start, lib, banked, out-of-range, data-in-text, no-asm, switch, pin-unproven, has-banked-twin, open-twin-sibling. So accepted + all refusals = candidates.

- pin-unproven derives the probed families from config/probes.tsv aliases through census family (alias `self` ignored). A new probe row lifts the refusal with no edit to the tool.
- The control is built from this run's evidence and holds no hard-coded addresses: one banked fn, one lib fn, a game start + 4, and two direct twins that pass every other reason. It expects exactly banked 1, lib 1, not-a-census-start 1, open-twin-sibling 1 and accepted 1. Its outputs go to `.run/draw/control/`.
