## Design notes
- Names `<alias>_<offset %x>`; header `slus_012_79_0`; tail `<alias>_trailing`. Comment per subsegment = `kind basis` of boundaries rows starting at that offset (joined `; `), none otherwise.
- Exe: top-level `[0x0, bin, slus_012_79_0]` + code segment start 0x800 vram 0x80018000. text_start = 0x8001b3b8 (asserted equal to header pc0 when reading gp). All 59 exe jtbls lie before pc0; no jr-target < text_start report in the fleet; no text_start > text_end.
- Type counts over the fleet: asm 275, rodata 238, data 80, bin 18 (1 header + 16 tails + WEP_S00 counted separately as dict segment).
- `--check` parses its own YAML format by regex (no PyYAML); checks count/N, unique aliases, boundary edges ⊂ cuts, tiling (first 0, strictly increasing, end marker = size, segment start = its first subsegment), vram, odd tail, WEP_S00, sha text, `*_path` under asm/ build/ assets/ src/. One FAIL line per failure category.
