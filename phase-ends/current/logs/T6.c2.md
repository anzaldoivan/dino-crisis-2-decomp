## Decisions
- Seed: permuter's `--seed`/force_seed is reproduce mode (`keep = … or self._force_rng_seed` → always keeps one candidate, never restarts from base). Not used; wrapper does `random.seed(S)` (default 1) + `PYTHONHASHSEED=0`; Randomizer seeds come from `random.randrange` so the whole run is deterministic.
- Permuter score cache (`_score_for_source`): repeat sources are not recompiled; logged `judged-cached` with the prior score (or prior not-judged status). D = distinct source sha1 over iters 1..W (base excluded, EvalError rows `-` excluded).
- Not judged: compile failure (o_file None), extract failure, permuter EvalError; scored PENALTY_INF (10**9) to the permuter, never in `best`.
- target.o: split asm prefixed `.include "macro.inc"` + `.section .text`; splat glabel/endlabel give a sized FUNC (checked with probe.extract); no wrapper sizing needed.
- base.c hazards refused (not stripped): `*/`, register pins, asm, `__attribute__`.
- TMPDIR = `<dir>/tmp` so permuter temp files stay under .run.
