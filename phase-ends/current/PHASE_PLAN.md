## Rationale
- Order: source and dumps first (T1), because every lever needs its pass attribution (G51, G52, DK-44) and DK-52 says confirm the version before reading. Then the registry and checker (T2) before the lever hunts, so T3-T5 each land rows into a checker that already refuses inert levers. Permuter (T6) and classifier (T7) consume the lever `before` drafts, so they follow the first lever task; the cookbook index (T8) follows all entry-writing tasks so its coverage assertion covers them.
- Five groups, not the kit's four: the kit has no combine file, and combine is a distinct tell source in 2.95.2 (regmove arrived after 2.7.2). Merging sched and reorg follows the kit's triage table and keeps the denominator honest at the -O2 mips1 flag set.
- Lever proof on game bytes, not only reproducers: GENERATION_PLAN.md:44 says inherited levers are hypotheses until re-proven on this game's bytes; a reproducer alone proves the compiler, not the game. Using `probe.py`'s existing target-fn compare (config/probes.tsv already carries alias/start/end) avoids a second comparer (G33 spirit).
- Lever tasks split by group cluster (T3 regalloc+combine, T4 sched-reorg, T5 expand-cse+loop): one source-reading context per cluster; each is ~120k. Preset has no hard rung, so the source-reading judgment is split across three medium tasks instead of one high one.
- Permuter = decomp-permuter at a pinned commit in the image (like `/opt/splat`), not a fetch into `.run/`: reproducible runs need its python deps pinned. Its compile script derives the triple from `make print-c A=<alias>` (G69), never restating flags. Scoring is relocation-masked (kit `masked_scorer` idea) by wrapping, never patching the permuter.
- "Proves iteration" (kit R61/DK-15): a run that reports no improvement must still show it iterated; so the check counts iterations and distinct candidate hashes, and prints `not judged` (compile failures) separately. Scorer control: the `after` draft scores 0.
- Plateau classifier inputs are masked instruction streams of draft vs target (kit residual_class.py), not score history; labels map to the five groups so a label points to triage-table rows. The planted plateaus are the lever `before` drafts: their class is known by construction, so the check is exact.
- Symptom index is generated, never hand-edited (kit R33), and lives in docs/ (cookbook/INDEX.md is written only by cookbook_add.sh).
- Compiler source staged under `.run/compiler-src/` (gitignored scratch, re-fetchable, sha256-pinned in config): GPL source is not game-derived but does not belong in the product tree; agents read it on the host.
- No `## Developer decides` items: tooling, image change, group list and proof definition are engineering calls made above.
