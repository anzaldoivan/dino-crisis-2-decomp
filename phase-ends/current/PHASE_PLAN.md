## Rationale
- Ladder wider than "2.7.2": the 4.7.0 SDK post-dates 2.7.2; the plan runs every fetchable build (5 old-gcc psx + esa psyq3.6, 4.0, 4.1, 4.3, 4.4, 4.5, 4.6) and lets bytes decide (G8). Plain/cdk variants join only if no psx build fits.
- Fingerprint survey before probes (T2): byte tells over the whole fleet narrow ASPSX version and `-G` cheaply and expose per-module variation before any C is written (G23, C0003). Counts per alias are derived, not game bytes.
- Probe harness (T3) is standalone + relocation-masked (proves body shape only, G10); the banks in T7 prove the real unit and the whole binary. Control rows: a self-compiled probe must match its own object (known-true) and a deliberately wrong flag must fail (known-false); the harness prints its denominator.
- Probe choice (T4): 3–5 small game functions from at least two modules (exe + one overlay), no jump tables, picked to discriminate: one with signed division (div expansion + trap form), one with gp-relative global access, one with a loop and a call, one leaf with a stack frame. "Exactly one triple" means one equivalence class of outputs; if two cc1 builds are byte-identical on every probe, T4 adds discriminating probes; a residual tie between builds that are the same compiler (e.g. psyq4.4 vs gcc-2.8.1-psx with identical output on all probes) is recorded with evidence and the PsyQ build pinned (era-native); the developer may override at the T4 review.
- T4 is `review: yes`: the fingerprint verdict is the phase's judgment the card routes to `/discuss max`; the review pause lets the developer open one before the pin lands in the Makefile. Not `effort: high` (preset `hard rung: none`; constitution forbids it).
- Real unit (T6/T7): a splat `c` subsegment whose range is driven by a tracked list `config/c_units.tsv` (alias, start, unit name); splat then emits per-function .s under the unit's nonmatchings dir and the C file `INCLUDE_ASM`s every unfinished function. Plumbing first with zero C bodies (T6), so a red gate in T7 is a body, not plumbing. Units start at function boundaries from `boundaries.tsv`/splat's own function list; true original TU boundaries are a 1.5+ question.
- No-ROM compile (T8): CI cannot see asm/ or the disc, so `compile_only.sh` runs cpp → cc1 → maspsx per unit and stops before `as` (the `.include` lines of INCLUDE_ASM resolve only in `as`); it proves the toolchain and the C, not bytes. The toolchain fetch is one shared script read by both Dockerfile and CI so the pins live in one file. PsyQ binaries are fetched, never committed (constitution Data Sources); CI fetching them is the same posture.
- Task split: toolchain (T1), survey (T2), harness (T3) are independent of one another's judgments; T2 needs no compiler and runs in parallel with T1. All coder tier `opus55` (the only tier).
- Triage: the one deferred item is a T5 note that nothing is pending; nothing to schedule.
