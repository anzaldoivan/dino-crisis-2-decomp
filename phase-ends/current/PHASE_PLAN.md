## Rationale
- Order: the function census (T1) is the denominator every other instrument divides by, so it is first and owns the phantom/truncation definitions. The second oracle (T2) checks T1's list before anything is built on it. Duplication/families/reach (T3) and the lib census (T4) consume T1's records. Progress (T5) reads T1+T4 denominators from the build. The harness (T6) is last because its pairs compare the instruments T1–T5 produce and it wires them onto the schedule.
- Definitions fixed here so no expert re-litigates them: phantom = a census entry that is not a real function (no instruction, outside its binary's `.text` per boundaries text-end, inside a jtbl/data-island span, or a start no oracle confirms) (DK-27). Truncation = bytes of `.text` not covered by exactly one census function, or a function whose extent crosses a forced boundary (the scanner dropped or cut rows; G19 count vs the over-approximating set = every text word). Second-oracle disagreement = a start present in one list and not the other, or the same start with a different end, after the documented normalisations only.
- Second oracle = Ghidra, all 83 programs, not exe-only: G19 demands the whole fleet and the work is local (free). Ghidra's known blind spot (C0020) is handled by a tracked, evidenced exception file (`config/oracle_exceptions.tsv`, each row with basis and the instrument that proves it); an exception without basis counts as a disagreement. The oracle output is cached as text (`config/ghidra/<prog>.functions.tsv`, start/size only — addresses, no bytes) so the comparison runs in the container and in the harness without Ghidra; staleness is caught by a recorded generator hash (G31).
- Duplication exact tier = relocation-masked words equal (HI16/LO16/J-target fields masked); near tier = opcode+register skeleton equal. Control: a function compared to itself relocated to another vram must hit exact tier; random-pair sample must yield ~0 near hits (DK-10: dedup wants under-matching). Reach = size × copies (DK-72/73). Unique tail = no exact or near sibling.
- Lib census extends exe-only signatures to overlays through T3's exact tier against exe lib functions rather than re-running psx_ldr on 82 overlays: cheaper, deterministic, and the exe rows are the evidenced set.
- Schedule = every `fleet_check.sh` run (every task that touches the build runs it) plus the weekly CI cron for the no-game pairs. Rejected: launchd/cron on the Mac (unattended lane with no evidence trail, G30); a separate `make harness` only (not running = not a guard).
- The harness pairs (≥ 5, DK-9 first four apply pre-campaign): matched? (banked.py source scan vs built-object bytes at census extents); compiles? (compile_only units vs Makefile-built C units); fleet green? (incremental rebuild hashes vs the clean run); scanner coverage? (census functions/bytes vs text words); oracle? (census vs Ghidra cache via oracle_diff); denominators? (progress denominators vs census). Each pair has a planted-disagreement negative control that must fail loudly (G25).
- Coder tier opus55 everywhere (one tier). No `effort: high`: preset max5 has no hard rung and every done-when here is test-arbitrated. No review tasks: no result needs the developer's sifting; exception rows are evidence-gated.
- Split: T1 and T6 are the largest (est 120k); splitting T1 further would separate the scanner from its own control.

## Risks
- Ghidra disagrees widely on overlays (raw imports, no signatures, time-shared windows) → T2 balloons. Detection: T2's first oracle_diff count; if > ~5% of starts per binary, the expert fixes the import (entry points from census-independent evidence: jal targets) before any exception rows, and returns `blocked` with the counts rather than mass-excepting.
- Census definition of a function is splat's glabel split, which can merge or split real functions (jlabel-referenced functions, 28 known). Detection: oracle_diff disagreements + boundaries crossing check in truncations.
- Firewall: masked hashes or opcode skeletons leaking into tracked files. Detection: audit_public.py in every verify; T3/T4 outputs only in `.run/`.
- fleet_check runtime grows past the 285 s tool-call ceiling with the harness attached. Detection: `elapsed` line; mitigate by running via `tools/run.sh --bg` + `--wait` (house rule §9).
- Exception file becomes a dumping ground hiding real census errors. Detection: oracle_diff counts an exception without basis+instrument as a disagreement; T2 done-when forbids excepting a census error.
