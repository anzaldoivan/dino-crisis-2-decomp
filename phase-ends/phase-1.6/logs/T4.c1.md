## Design notes
- Deviation: define-only name form not used. banked HEAD regex (banked.py:14) and census C_HEAD need `func_<ADDR>(...) {` in the unit; a full fn in the .inc.c would also be banked as a non-address name. So the signature line stays in the unit, the inc holds the body statements.
- Keys: both fns' words from retail (dup_census.binary_words; ends from .run/census/functions.tsv), masks from dup_census.pairs in RAM range (same rule census uses for C-defined fns). Independent of asm/ (dc.sh sync wipes /work/asm and /work/build).
- Bindings: exemplar define symbols own masked operands (J: exact; lui/lo: largest symbol <= addr); one agreed delta per symbol. Here D: +0x3E54, callee: delta 0 (same lib fn func_80047814).
- Scratch tree .run/propagate/<alias>/: copied config/ (yaml base_path ../.. must resolve inside scratch, a symlinked config/ would resolve to the real root and let splat rm -rf the real asm/<alias>), copied src/ Makefile, symlinked include/ and extracts; fresh asm/ build/.
- Member unit gains the exemplar's missing `#include`s (first try failed: `p' undeclared, Obj unknown without dc2.h).
- If the member already holds an instantiation, it must equal the derived one (drift = FAIL), so post-apply dry runs check the committed unit.
- Control: `--apply --plant --family <first>` (member callee rebound to func_<member>: links, wrong jal) must rc 1 with a `FAIL sha1` line and src/ config/ build/ byte tree-hash unchanged.
