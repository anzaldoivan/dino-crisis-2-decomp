## Parser choices (check against definitions)
- Function end = last `/* off vram word */` line before next glabel/section → trailing alignment `nop`s after `endlabel` belong to the preceding function (e.g. exe 0x80078D7C..0x80078D80 after `endlabel func_80078C44`). Stopping at endlabel would turn those into gaps.
- `.word` lines in `.text` (dlabel data inside text) count as covered only if under a glabel; before the first glabel they are uncovered.
- Oracle (a): any `func_XXXXXXXX` token on lines not starting glabel/endlabel/.size/.type/nonmatching/dlabel/jlabel; exe uses the union of all aliases.
- Oracle (b): prev function's last non-nop is `jr|j|b|beq $zero,$zero|beqz $zero` (with its delay slot present) or the insn before it is.
