## Pair mechanics (side B)
- matched B: `.ent` names from `build/<alias>/src/**.c.s` (cc1 output; INCLUDE_ASM glabels are FUNC in the .o too, so `.ent` is the filter), own ELF32 reader for .o (.text, .symtab, .rel.text) and `build/<alias>.elf` (link address). Masks: R_MIPS_32 full, 26 low 26, HI16/LO16/GPREL16 low 16, other types full word. Retail offset: exe `v - t_addr(hdr 0x18) + 0x800`, else `v - loadmap base`.
- coverage B: region = first asm|c subsegment vram .. boundaries text-end end; census Y = region − data spans (census excludes spans from Y). Census exposes per-span lines (`<alias>: data in text 0x..0x..`), so per-span check used, no deviation. gotcha: `census.py --check` prints fixture totals (`text bytes covered: 56 of 64`) after the real block; harness takes the first block.
- bin_wep_s00 has no text region (no asm|c subsegment, no text-end) → must have 0 rows/spans and census 0/0.
- In-run controls: fleet/compiles/denominators perturb B in memory; coverage duplicates one row (overlap); matched recomputes B with one retail byte flipped; oracle = its own `control:` lines all ok.
- Plants: fleet zeroes one clean sha; compiles injects a FAILED for the first unit; coverage drops first census row; matched flips retail byte of first banked function; oracle `--plant-start slus_012_79:0x8001b45c`; denominators drops one game row.
