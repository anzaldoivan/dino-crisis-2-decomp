# Oracle comparisons are symmetric and unseeded

A comparison against an oracle (Ghidra, the emulator) counts disagreements on both sides, with no exemption lists.
When the oracle missed something, recover it with the oracle's own machinery (e.g. Ghidra's decompiler inside a
rolled-back transaction), never by seeding it with our own extents or answers: a seeded oracle only echoes us.
A load-base proof is >= 3 RAM datapoints or a before/after diff, with fixed ranges and named exclusions decided
before the run and never widened to make it pass.

Origin: phase 1.2, T3.1, T5, T7 (`binding:` lines).
