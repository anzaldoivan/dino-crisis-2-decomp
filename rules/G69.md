# The compiler triple and its flags are defined once, in the Makefile

`CPP CC1 MASPSX CPPFLAGS CFLAGS MASPSXFLAGS` live only in the `Makefile`. Tools that need them (probe.py,
compile_only.sh, any future harness) read them with `make -s print-c A=<alias> CCDIR=<dir>`, never re-type them.
Per-module variation goes through the per-alias hooks `CPPFLAGS_<alias>`, `CFLAGS_<alias>`, `MASPSXFLAGS_<alias>`
(on the make command line or in the Makefile), never a second compile rule. A second copy of the flags drifts, and a
probe that passes under a copy proves nothing about the build.

Origin: phase 1.4, T5 and T8 (`binding:` lines).
