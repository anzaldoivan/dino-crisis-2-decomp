# G70 — A scanner's control must be able to fail

A scanner registered in `config/scanners.tsv` (or any instrument a milestone counts) passes its control only on a
line that a broken scanner would not print:
- the tool's own every-run control line (known-true probe or planted negative evaluated each run), or
- a chained planted negative (`cmd && ! cmd --fixture …`) whose failure line is matched.

Never an unconditional line (a banner, a count that always prints, a `check: OK` that does not depend on the control).
The denominator regex's last group is an integer ≥ 1 (G27, G28).

Why: a control that cannot fail proves nothing.
Check: `tools/harness.py --scanners` → `scanners: S of S denominator+control ok`.
