# G33 — A verdict names its instrument; never re-implement a gate you have
id: G33 · group: G · status: active · tags: decomp,instruments · origin: decomp-architect · added: 2026-09-30

A negative verdict records which tool produced it; a one-off script never stands in for the real gate (it skips the real
gate's pre-checks and mints false walls). One implementation, many callers: the change that creates or alters a tool also
wires the sibling tools that should call it and updates its ops row and its cookbook or playbook entry — integrating an
agent's tool change is a tool change. An end-of-session documentation audit is a symptom of not having done it during.
