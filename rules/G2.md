# G2 — Oracle precondition
id: G2 · group: G · status: active · tags: decomp,oracles,gate · origin: decomp-architect · added: 2026-09-30

Before any reverse-engineering task, verify the disassembler's server with one cheap call. If it is down, stop and ask the
developer to start it; never proceed on cached assumptions. After a restart or a program switch, pause and ask the developer
to reconnect the client — the agent cannot. In a live co-op session (the developer at the emulator or the controls, pacing on
the agent's replies), end the turn with the answer they are waiting on before starting long work, and announce a long grind
with its expected duration: only a turn's final message is guaranteed to be seen.
provenance: BFM G2 + R29; memory seed "answer before grinding in live co-op" (folded at the PA3 port)
