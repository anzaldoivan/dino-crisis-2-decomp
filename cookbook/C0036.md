# Propagating a label through duplicate classes needs a purity rule
- Tiny bodies (empty `jr ra` functions) are shared by labelled and unlabelled code, so an exact-duplicate class can
  hold both lib and game members.
- Size thresholds are arbitrary. Propagate a label only when the class has no member of the other label in the
  evidenced set (lib-pure: ≥ 1 exe lib member, 0 exe non-lib members).
- Source: Phase 1.5 T4 (tools/census.py lib pass).
