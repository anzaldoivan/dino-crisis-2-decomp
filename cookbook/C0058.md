# Readability markers inside a backslash-continued #define

Symptom: a `//` comment in a multi-line `#define` swallows the next continued line. Line splicing (`\` + newline) happens before comments are removed.

Technique: write a block comment `/* !FAKE: <reason> */` on the line of the construct, before the trailing `\`. cpp replaces the comment with a space. Whitespace in a replacement list collapses to one space. So the expanded call-site text stays byte-identical.

Check: run `cc -E` on a call-site unit with the old header and the new header. Compare the text without the line markers. Only the header's own line markers move when the header grows.

Floor rule (psxd_floor.py 0.6.3): a pin at a line that invokes an include/gte.h macro needs a reasoned marker inside that macro's definition. One marker covers one pin. The markers of the call site never cover it. Origin: T29 (GTE_CTC2_024, 3 pins).
