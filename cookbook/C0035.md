# Relocation-masked dedup keys must mask raw hi/lo pairs and lo-reuses
- splat/spimdisasm symbolizes only the first `%lo` of a `%hi` register and sometimes emits raw
  `(0x… >> 16)` / `(0x… & 0xFFFF)` pairs.
- A relocation-masked dedup key must mask those raw forms and every lo-use of a register last written by an
  annotated hi (addu-propagated), or relocated copies of the same function miss each other.
- Never key masks on address values (under-matching). Prove the masking with an independent relocator control
  (move every field by a fixed delta; all functions must stay exact).
- Source: Phase 1.5 T3 (tools/dup_census.py).
