# C0014 — PsyQ libcard _patch_card self-modifies code at runtime
tags: psyq,emulator,ram-proof,smc · date: 2026-10-01 · phase/task: 1.2/T3 · origin: phase-ends/current/tasks/T3.md

PsyQ libcard `_patch_card*` routines rewrite their own code at runtime. A RAM-vs-file .text proof must expect self-modifying code in those extents and exclude them by name.
