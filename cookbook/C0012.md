# C0012 — Ghidra annotation deltas must drop ANALYSIS/DEFAULT-sourced labels
tags: ghidra,annotations,determinism · date: 2026-10-01 · phase/task: 1.2/T2 · origin: phase-ends/current/tasks/T2.md

An exported Ghidra annotation delta must drop labels whose source is ANALYSIS or DEFAULT: switch `caseD_*` labels drift between identical analysis runs, so keeping them breaks export-rebuild-export byte equality.
