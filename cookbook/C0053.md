# C0053 — Sync wipes split asm, so regenerate it with make split ONLY=<alias>
tags: build,split,docker,permuter · date: 2026-10-02 · phase/task: 1.7/T6 · origin: phase-ends/current/tasks/T6.md

**Problem** — A tool that needs the split `.s` of a game fn (permuter `target.o`, diff tools) fails after
`dc.sh sync`. Split asm is generated output (H1), and the sync wipes it from the container volume.

**Technique** — When the `.s` is absent, the tool regenerates what it needs with `make split ONLY=<alias>`. The tool
never assumes that the asm of a previous run survives. Never track or copy split asm (G12).
