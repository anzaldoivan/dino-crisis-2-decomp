# C0053 — Split asm is wiped by sync; regenerate it with make split ONLY=<alias>
tags: build,split,docker,permuter · date: 2026-10-02 · phase/task: 1.7/T6 · origin: phase-ends/current/tasks/T6.md

**Problem** — a tool that needs a game fn's split `.s` (permuter `target.o`, diff tools) fails after `dc.sh sync`:
split asm is generated (H1) and the sync wipes it from the container volume.
**Technique** — the tool regenerates what it needs with `make split ONLY=<alias>` when the `.s` is absent, never
assumes a previous run's asm survives; never track or copy split asm (G12).
**Origin** — phase 1.7 T6.
