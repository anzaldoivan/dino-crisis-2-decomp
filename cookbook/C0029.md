# INCLUDE_ASM through maspsx needs macro.inc in the assembled file

With the cc1 → maspsx → GNU as pipeline, `INCLUDE_ASM` pulls splat's .s, which uses `glabel`/`jlabel` macros. The
macros are not defined in the cc1 output, so `as` fails. Prepend `.include "macro.inc"` to the maspsx output
(`.m.s`) before assembling (the Makefile C branch does this).
