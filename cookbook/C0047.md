# C0047 — If/else arm order: jump.c swaps an early-return then-arm last; invert the test to lay it
tags: codegen-map,jump,block-order,branch-polarity,delay-slot,dbr,sched-reorg · date: 2026-10-02 · phase/task: 1.7/T4 · origin: -

tell: if/else arms in swapped order (early-return arm at fallthrough vs at the branch target; same insns, branch polarity flipped)
group: sched-reorg

**The residual** — game fn `slus_012_79:0x8005EE58` (16 words; test a signed byte counter, either clear a flag and return 1
or decrement, pop a pointer and return 0). Natural draft `if (s->f9d == 0) { s->f9b = 0; return 1; } s->f9d--; ...; return 0;`
has the same 16 insns as the game but first differs at word 3: ours tests with the opposite polarity and lays the
decrement arm at fallthrough, the flag arm last; the game has the flag arm at fallthrough. Slot contents are the same in both.
Reproducer `tools/probes/levers/repro/jump_else_return.c` (a natural, b inverted, c if/else with a join: never swapped).

**The mechanism** — not expand, not dbr: jump.c. `.rtl` of the before draft (expand, do_jump) jumps over the then-arm
`(jump_insn 16 14 18 (set (pc) (if_then_else (ne:SI (reg:SI 83) ...` with the then-arm first; `.jump` (first
jump_optimize, toplev.c:3843) has `(jump_insn 16 14 31 (set (pc) (if_then_else (eq:SI (reg:SI 83) (const_int 0 [0x0]))
(label_ref 28) (pc)))` and the else-arm first. Site: jump.c:1796 "Look for if (foo) bar; else break;": condjump to
label1, range1 ends in a simplejump to label2 (the return label), range2 after label1 ends in a jump + barrier →
invert_jump (:1830) and splice the two ranges (not on the first iteration, :1808; after reload only without delayed
branch, :1815, so jump2 never does it on MIPS). Both arms here end in `return`, so the early-return then-arm always
lands last. The order then survives every later pass unchanged (scratch per-pass marker order: `.jump` to `.dbr` equal).
Delay slots are dbr and identical before/after: bne slot `move $2,$0` stolen from the target thread, both `j $31` slots
filled backward; all printed by cc1 inside `.set noreorder` (maspsx adds nothing).

**The lever** — when the game lays the arms opposite to the draft and both arms end in `return`, invert the test and swap
the arms: write the arm the game puts at the branch target as the early-return then-arm (`if (s->f9d != 0) { s->f9d--;
...; return 0; } s->f9b = 0; return 1;`). jump.c moves it last. An if/else that joins (no return in the arms) is not
swapped; its source order is the layout. Check `.rtl` vs `.jump` polarity before blaming dbr.

**The byte proof** — `config/levers.tsv` row `swap-returning-arm`: `tools/probes/levers/swap-returning-arm.before.c`
differs from the game at word 3; `.after.c` (test inverted, arms swapped, nothing else) is byte-identical
(relocation-masked) under the pinned triple; `tools/codegen_map.py --check --groups sched-reorg` → proven.
