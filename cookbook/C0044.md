# Run container-orchestrating verifiers on the host

A container-orchestrating verifier has clauses that call `dc.sh` themselves (phase-end `phaseend_index.py verify`).
It cannot pass when you run the verifier itself through `dc.sh run`. The container has no docker and no git, so
every clause is RED.

- Run such a verifier on the host: `bash tools/docker/dc.sh sync && PY tools/phaseend_index.py verify`.
- A task `verify:` line that wraps an orchestrator in `dc.sh run` is a plan bug. The expert runs it on the host and
  records the deviation.
