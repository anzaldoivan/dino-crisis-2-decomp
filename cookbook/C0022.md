# splat: carve a pre-code data head of an overlay as rodata

- Symptom: `mipsel-linux-gnu-as -march=r3000` rejects MIPS II+ opcodes (ll/sc/beql/...) in a splat `.s` of an overlay. The bytes are a data head before the first function, and splat disassembled them as code.
- Fix: the code segment starts at the first stack-frame prologue (`addiu $sp,$sp,-N`). Everything from the overlay base (or the last jump-table end) to that prologue is a `rodata` subsegment.
- In 1.3, this fixed 10 of 83 binaries (72/83 → 82/83 with the other fix). The generator is the head_end carve of `tools/splat_gen.py`.
- Source: phase 1.3 T4.
