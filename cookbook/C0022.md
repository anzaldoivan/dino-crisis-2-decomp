# splat: carve a pre-code data head of an overlay as rodata

- Symptom: `mipsel-linux-gnu-as -march=r3000` rejects MIPS II+ opcodes (ll/sc/beql/...) in a splat `.s` of an overlay; the bytes are a data head before the first function, disassembled as code.
- Fix: the code segment starts at the first stack-frame prologue (`addiu $sp,$sp,-N`); everything from the overlay base (or last jump-table end) to it is a `rodata` subsegment.
- In 1.3 this fixed 10 of 83 binaries (72/83 → 82/83 with the other fix). Generator: `tools/splat_gen.py` head_end carve.
- Source: phase 1.3 T4.
