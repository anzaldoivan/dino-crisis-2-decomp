# Count gp-relative accesses before picking -G

A `gp_value` in the splat yaml says where `$gp` points, not that the code uses it. Before choosing `-G<n>` for cc1
and the assembler shim, count `%gp_rel`/`($gp)` loads and stores in the split asm (tools/cc_fingerprint.py does this
per module). Zero gp-relative accesses means `-G0`; a nonzero `-G` would emit gp-relative code that cannot match.
