# Prefer i686 wibo under Apple-silicon Docker

Windows PsyQ `CC1PSX.EXE` builds need a PE loader (wibo). On Apple silicon, Docker's amd64 emulation (Rosetta)
runs the i686 wibo build; the x86_64 wibo build fails with `invalid gdt selector index 4`. Pin the i686 release
(wibo 1.2.0 i686 here, `config/toolchains.tsv`) and smoke-test one compile before trusting the candidate set.
