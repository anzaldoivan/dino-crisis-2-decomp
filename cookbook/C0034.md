# A stack prologue after an unconditional transfer is a function start splat merges
- splat can merge two functions when the second follows `j`/`jr` + delay slot and nothing inside jumps to it.
- Rule: a stack prologue (or the first non-zero word) after an unconditional transfer + delay slot, not targeted from
  inside the function (branch or jtbl), starts a new function. Also split at any jal target inside a function.
