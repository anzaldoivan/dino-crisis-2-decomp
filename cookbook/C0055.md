# Hand splice of a MATCH draft whose constant initializers live in splat rodata

Symptom: a draft scores MATCH standalone, but carve/as-is banking fails with `sha1sum: WARNING: 1 computed c`
(binary grows, later addresses shift). Cause: constant aggregate initializers (`T b = {0, 0, 255, ...};`) put the
constants into the C unit's `.rodata`. Retail keeps them in a splat rodata segment. Carve and splat_gen place no
`.rodata` subsegment for C units (no rodata migration).

Recipe (T8.c345 0x8006cb1c, T16.c1 0x8004c0b4):
1. In the target asm, find the `%hi/%lo(D_<addr>)` pairs that address the initializer copies (`lui` + `addiu` then
   `lw`/`sw` word copies). Each label is one initializer, in source order.
2. In the unit: `extern T D_<addr1>, D_<addr2>, ...;` (comment: splat rodata) and replace each constant initializer
   with a struct copy `T b = D_<addr1>;`. Non-constant initializers (built on the stack) stay as drafted.
3. Replace `INCLUDE_ASM(..., func_X)` with the body. Drop draft copies of shapes already in `dc2.h` or the unit.
   The types scanner flags duplicates, so hoist a shared shape into `dc2.h`.
4. Build `make build ONLY=<alias>`, then run the clean fleet gate. Copies stayed `lw`/`sw` for a short struct.
   If `lwl`/`lwr` appears, raise the alignment of the extern. Never touch retail.
5. Record the bank: `config/journal.tsv` row `alias start <draft wave> splice banked MATCH hand splice <commit> (...)`.
   `wave.py --check` accepts route `splice`. No tool writes the row.

Also a hand splice is the only path when carve refuses a unit with C bodies outside the target's range (0x8006af9c).
