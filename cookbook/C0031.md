# Classify uncovered text spans by evidence, not by trimming the range
- A text range taken from the first asm subsegment can still open with data words (a `dlabel` inside `.section .text`).
- Do not trim the range to hide them. Classify each uncovered span. A span is data-in-text when all of these
  conditions are true:
  - Every word is data/invalid per spimdisasm.
  - There is no control-flow target that lands in the span.
  - The span holds an invalid insn, or a reference from outside uses it as data.
- Data-in-text leaves the denominator, and the census reports it (`data in text: D B (n spans …)`). Anything else uncovered is a truncation.
- Source: Phase 1.5 T1 (tools/census.py and docs/ops/decomp-environment.md `### Function census`).
