# C0018 — Snapshot RAM before writing a decompressor to prove an overlay base
tags: emulator,overlay,compression,ram-proof · date: 2026-10-01 · phase/task: 1.2/T5 · origin: phase-ends/current/tasks/T5.md

Before building a decompressor to prove where a compressed overlay loads, snapshot RAM after load: the decoded image often equals a loose uncompressed copy on the disc, which then serves as the reference.
