# PSX ISO da entries point into the CD-DA track

A PSX ISO9660 file entry with the `da` attribute has its extent in the CD-DA track (Track 2), not in Track 1.
An extractor reading Track 1 must detect extent >= Track 1 sector count and skip the entry (print it as a da-file count, no manifest record).
