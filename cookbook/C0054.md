# C0054 — Plateau classifier: test length drift before index-wise labels
tags: plateau,classifier,diff,codegen-map · date: 2026-10-02 · phase/task: 1.7/T7 · origin: phase-ends/current/tasks/T7.md

**Problem** — A classifier that labels a non-matching draft by index-wise diff overstates the residual. One inserted
or dropped insn shifts the tail, so every later index differs and the label reads as a mass reorder.

**Technique** — Align index-wise under the relocation mask of the draft. But before any per-index label, test length
drift first (size delta, then `tail`/`partial` drift). Use a fixed first-match label order (C0043). Print counts,
indices and mnemonic names only (G73).

**Origin** — phase 1.7 T7 (`tools/plateau.py`, kit residual_class.py rationale).
