# C0054 — Plateau classifier: test length drift before index-wise labels
tags: plateau,classifier,diff,codegen-map · date: 2026-10-02 · phase/task: 1.7/T7 · origin: phase-ends/current/tasks/T7.md

**Problem** — classifying a non-matching draft by index-wise diff overstates the residual: one inserted or dropped insn
shifts the tail, so every later index differs and the label reads as a mass reorder.
**Technique** — align index-wise under the draft's relocation mask, but test length drift first (size delta, then
`tail`/`partial` drift) before any per-index label; fixed first-match label order (C0043). Print counts, indices and
mnemonic names only (G73).
**Origin** — phase 1.7 T7 (`tools/plateau.py`; kit residual_class.py rationale).
