# psx_ldr object-offset labels turn jumps into "calls"
- psx_ldr signature application creates functions at object-offset labels (`<OBJ>_OBJ_<off>`), often on epilogues and loop heads.
- Ghidra then retypes a `j` to such a label as a call. Check the opcode (jal vs j), not the reference type, before counting a call.
- Merge a Ghidra function whose every ref is internal flow from the preceding function (oracle normalisation n3).
