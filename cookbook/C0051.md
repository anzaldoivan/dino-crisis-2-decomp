# C0051 — Check which scheduler file a gcc target builds before citing it
tags: gcc,sched,haifa,sched-reorg,codegen-map · date: 2026-10-02 · phase/task: 1.7/T4 · origin: phase-ends/current/tasks/T4.md

**Problem** — a scheduler lever is cited against the wrong source file. gcc 2.95.x builds haifa-sched.c only for
alpha/hppa/powerpc/rs6000/sparc/m32r (configure.in `sched_prefix`, 2.95.2 :3552-3557); mips (PSX) uses the old list
scheduler `gcc/sched.c`.
**Technique** — before citing scheduler source, check configure.in's `sched_prefix` for the target and confirm with the
`-da` `.sched` dump: sched.c prints `;; ready list at T-%d:`; haifa prints its own strings. Haifa-only rules
(REG_WEIGHT, interblock, depend_count) do not exist under sched.c.
**Origin** — phase 1.7 T4 (sched-reorg lever, C0048).
