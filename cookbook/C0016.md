# C0016 — Find a PS1 game's file table by scanning the exe for disc LBAs
tags: ps1,iso,file-table,loader · date: 2026-10-01 · phase/task: 1.2/T4 · origin: phase-ends/current/tasks/T4.md

Scan the exe for u32 words equal to the manifest's file LBAs; a stride-8 run of hits is a `{u32 lba, u32 size}` file table, usually indexed in LBA order.
