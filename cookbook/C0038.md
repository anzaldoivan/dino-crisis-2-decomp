- Use the Myers/Hyyro bit-parallel edit distance on Python ints over relocation-normalised word tokens.
- First, dedupe identical token sequences. Then prefilter by length +-25% and an opcode-histogram lower bound.
- The run takes ~20 s for 3426 fns and uses no numpy. Source: tools/twins.py (Phase 1.6 T1).
