# C0010 — Ghidra on macOS arm64 needs locally built decompiler natives
tags: ghidra,macos,psx_ldr · date: 2026-10-01 · phase/task: 1.2/T1 · origin: phase-ends/current/tasks/T1.md

Ghidra release zips lack macOS arm64 decompiler natives. Build them (`support/buildNatives` or make in the Decompiler src) or ghidra_psx_ldr's analyzer aborts silently after the first range, giving 0 PsyQ signature hits.
