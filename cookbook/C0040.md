# Shared bodies (*.inc.c) are excluded from per-unit scanners

- A propagated body included inside function braces is not a translation unit.
- Every tool that compiles or counts each src .c as a unit (compile_only, harness pair checks) must skip *.inc.c, or unit-count pairs disagree (6 vs 5).
- The build rule must depend on src/shared/*.inc.c so an edit rebuilds every instantiating alias. Source: Phase 1.6 T4.
