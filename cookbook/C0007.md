# dumpsxiso writes XA/STR files at 2336 B/sector

dumpsxiso emits Form 2 / mixed (XA, STR) files at 2336 bytes per sector, while the ISO9660 size field says 2048 x sectors.
Compare such files by sector count, not by ISO length; an extractor matching dumpsxiso must write 2336 B/sector for them.
