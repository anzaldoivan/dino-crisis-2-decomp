# C0052 — decomp-permuter --seed is a replay, not a search seed, so seed random in a wrapper
tags: permuter,determinism,seed · date: 2026-10-02 · phase/task: 1.7/T6 · origin: phase-ends/current/tasks/T6.md

**Problem** — The `--seed` of decomp-permuter looks like an RNG seed, but it is a reproduce mode. It replays one
candidate. It does not seed a search. Two "seeded" searches are not reproducible.

**Technique** — Run the permuter through a wrapper that calls `random.seed(S)` before the search. Use threads 1 and
`PYTHONHASHSEED=0`. Record S with the run. Never pass the permuter's own `--seed` for a search.

**Origin** — phase 1.7 T6 (`tools/permute.py`, `tools/permuter/permuter_run.py`).
