# C0052 — decomp-permuter --seed is a replay, not a search seed; seed random in a wrapper
tags: permuter,determinism,seed · date: 2026-10-02 · phase/task: 1.7/T6 · origin: phase-ends/current/tasks/T6.md

**Problem** — decomp-permuter's `--seed` looks like an RNG seed but is a reproduce mode: it replays one candidate, it
does not seed a search. Two "seeded" searches are not reproducible.
**Technique** — run the permuter through a wrapper that calls `random.seed(S)` before the search, with threads 1 and
`PYTHONHASHSEED=0`; record S with the run. Never pass the permuter's own `--seed` for a search.
**Origin** — phase 1.7 T6 (`tools/permute.py`, `tools/permuter/permuter_run.py`).
